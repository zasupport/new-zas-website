# Locally hosted fonts

Inter Latin variable weight font and DM Mono Latin normal 300/400/500 were obtained from Fontsource packages version 5.3.0 on 21 September 2026. Their licence texts are included alongside the font files.

The app uses `next/font/local`. Font assets therefore exist in the checkout before the build starts; no build-time Google Fonts request is required. Retain the licence files and verify file hashes when changing the assets.
